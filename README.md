## 🏃‍♀️ Cómo Ejecutar el Proyecto

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Ejecutar tests**:
   ```bash
   npm run test:all
   ```

3. **Ver cobertura**:
   ```bash
   npm run test:cov:controller
   ```

4. **Iniciar aplicación**:
   ```bash
   npm run start:dev
   ```
